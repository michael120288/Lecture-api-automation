## Task 5 — Notifications
```js
pm.test('Status 200', () => pm.response.to.have.status(200));
pm.test('Notifications is array', () => {
  pm.expect(pm.response.json().notifications).to.be.an('array');
});
```

**Why might notifications be empty?**
Notifications are generated by server events: someone followed you, reacted to your post,
or commented. On a fresh test account with no activity, `notifications: []` is expected and correct.
Always assert the shape (is array) rather than the count when dealing with event-driven data.
